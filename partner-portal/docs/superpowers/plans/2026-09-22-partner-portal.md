# Partner Portal Implementation Plan

**Goal:** Реализовать выбранный пользователем вариант 1 как интерактивный frontend-прототип.
**Architecture:** React SPA с навигацией в памяти, Vite и мок-данными. Компоненты таблицы, модального окна, поля и статуса переиспользуются.
**Tech Stack:** React 19, Vite 6, Phosphor, Mont.
**Spec:** `design/reference.png` и ТЗ из пользовательского вложения. Текущий проход: внешний партнёр.

## Ограничения
- Сохранить композицию, контент и бренд первого показанного изображения.
- Не подключать реальные операции, интеграции, авторизацию и хранение данных.
- Основные сценарии проверять в браузере; не писать тесты, дублирующие низкорисковую реализацию прототипа.

## Задачи
- [x] Инициализировать Product Design template; сохранить визуальный эталон и оригинальные бренд-материалы.
- [x] `src/data.js`: мок-лиды, заявки и начисления; CSV/TXT экспорт.
- [x] `src/components.jsx`: доступный dialog, таблица лидов, поля формы, статусы.
- [x] `src/App.jsx`: обзор, поиск/создание лидов, карточки, заявки, кандидаты, документы, финансы и профиль.
- [x] `src/styles.css`: точность макета на desktop, адаптация до мобильного экрана.
- [x] Проверить `npm run build`, основные сценарии в браузере, консоль, desktop/mobile.
- [x] Сравнить screenshot с эталоном, исправить существенные расхождения, записать `design-qa.md`.

## Проверки в браузере
Создать лид с вымышленными данными; найти его через поиск; открыть карточку; проверить пустую выдачу. Изменить статус кандидата и проверить уменьшение счётчика задач. Открыть и согласовать демоакт. Проверить остальные разделы, Esc и мобильное меню.
