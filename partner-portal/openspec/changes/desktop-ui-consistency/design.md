# Design

## Context

Сверены архитектурный документ `docs/superpowers/specs/2026-09-30-full-partner-portal-design.md`, раздел Frontend действующего `full-partner-portal-specification/design.md`, App.jsx, CSS разделов, API и e2e. Существуют React/Vite SPA, единый data-access layer, модульный backend и серверная проверка прав. Изменение остаётся в presentation layer.

Корень дефекта: grid-элемент main имеет автоматическую минимальную ширину и автоматические внешние отступы. Минимальная ширина шести колонок канбана растягивает main и документ; короткие разделы, напротив, сжимаются и центрируются. Дополнительно общие стили input влияют на размеры вложенных фильтров.

## Decisions

Рабочая область получает min-width:0, width:100%, margin:0 и общие отступы. Меню имеет постоянную ширину; контент использует доступное место. Канбан прокручивается внутри собственного контейнера. Формы могут ограничивать внутреннюю ширину, сохраняя общую левую границу.

Общий компонент заголовка размещает h1 слева, главное действие справа; фильтры расположены ниже и переносятся целыми группами. Страницы лидов и заявок владеют своим заголовком и действиями, поскольку создание формы управляется локальным состоянием. Повторяющиеся заголовки и основные действия в пустом состоянии убираются; опубликованные строки используются повторно.

Общие CSS-переменные задают основной синий, контрастный текст, фон, границы, 40 px минимальной высоты действия, 32 px компактного действия, 14 px текста кнопки и 8 px радиуса. Длинная подпись переносится, увеличивая высоту; иконка не сжимается. Правила не фиксируют высоту текстовых контейнеров и не маскируют переполнение документа overflow:hidden.

## Validation

Frontend-регрессии проверяют геометрию настоящих компонентов на искусственных API-ответах: границы документа, главные действия, общий левый край заголовков, группы фильтров, длинные названия и ошибки. Основной поток дополнительно проверяется полным Compose e2e с настоящими backend/PostgreSQL и тестовыми провайдерами. После публикации проверяются assets и авторизованный UI стенда без создания записей.
