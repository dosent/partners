## ADDED Requirements

### Requirement: Пустой русский черновик получает редактируемые значения по умолчанию
Экран управления регистрационным контентом SHALL подставлять согласованный набор русских значений по умолчанию во все пустые обязательные строки, метаданные трёх типов оферт, метаданные согласия и ключ логотипа `simbirsoft`.

#### Scenario: Первое открытие незаполненного черновика
- **WHEN** администратор открывает экран редактирования без сохранённого русского черновика
- **THEN** форма SHALL показывать значения по умолчанию для всех обязательных строк, версии и заголовка каждой оферты, версии и заголовка согласия и логотипа
- **AND** каждое значение SHALL быть доступно для редактирования
- **AND** тексты тел оферт и согласия SHALL оставаться пустыми, если они ранее не были введены

#### Scenario: Загрузка черновика с пустыми обязательными полями
- **WHEN** загруженный черновик содержит отсутствующие или пустые обязательные значения
- **THEN** редактор SHALL показывать для них значения по умолчанию
- **AND** непустые значения администратора и дополнительные ключи SHALL сохраняться без изменений

#### Scenario: Сохранение отредактированных значений
- **WHEN** администратор изменяет начальные значения и сохраняет черновик
- **THEN** редактор SHALL отправлять и отображать изменённые значения
- **AND** изменение SHALL NOT автоматически публиковать черновик

#### Scenario: Публикация без утверждённых юридических текстов
- **WHEN** администратор пытается опубликовать черновик без тела хотя бы одной оферты или согласия
- **THEN** существующая серверная проверка SHALL отклонить публикацию
- **AND** значения по умолчанию SHALL NOT подменять юридические тексты
