# Проверка исправления загрузки файлов — 30.10.2026

## Подтверждённые дефекты

- `S3ObjectStorage` формировал CanonicalHeaders в порядке host/content-type, а SignedHeaders — content-type/host. Настоящий MinIO отвергал PUT с HTTP 403. Новый integration-тест наблюдал этот отказ до исправления и прошёл после согласования алфавитного порядка.
- nginx имел стандартный лимит тела запроса 1 MiB при разрешённых в продукте файлах до 20 MiB. Искусственный запрос без аутентификации на стенде :8088 подтвердил HTTP 413. Лимит nginx согласован с backend multipart max-request-size: 21 MiB.

В журнале исходной загрузки заявка была сохранена с HTTP 200, а запрос вложения завершился HTTP 503 примерно через 15 секунд. Отдельная проверка ClamAV на искусственных PDF/DOCX прошла; оригинальный пользовательский документ не читался. Причина исходного HTTP 503 до конкретного внутреннего исключения не подтверждена. Исправлены независимо подтверждённые дефекты сохранения файлов.
